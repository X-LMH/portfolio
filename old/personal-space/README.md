本轮实际浏览器截图与交互检查记录保存在不发布的 `qa/cross/`，此前证据仍在 `qa/fusion/`。六套共十二张预览图均由真实 1366×768 浏览器视口重新截取。如修改内容或布局，重新截图后运行 `python scripts/prepare-fusion-previews.py` 更新预览图。

## 编辑与构建

修改 `templates/` 中的完整HTML。运行 `python scripts/build-pages.py --fresh-only` 仅生成本轮五套；不带该参数会从全部模板重新生成所有页面。

运行 `python scripts/check-site.py` 检查静态链接、锚点、重复ID、公共行为接口以及独立布局要求。新增布局分别位于各自目录，不载入旧 `base.css` 或 `landing.js`。

`content.js`、`shared.js`、`reading.js` 和 `behavior.js` 保留原接口。资料使用 `personal-space-profile`，主题使用 `personal-space-color`。保存只在当前浏览器生效；要向所有访客展示真实资料，须改源码后重新发布。

`fresh.css` 是行为基础样式，不规定各方案布局；`fresh-ui.js` 管理揭示、hash视图和分类筛选。弹窗/输入时不切幕，非活动视图hidden/inert，支持前进后退与减少动态效果。玻璃有实底回退。

## 素材与验证

新增五套没有AI图片或人物主视觉，仅使用HTML/CSS与局部SVG线稿。旧照片仍按 `dist/assets/PHOTO-SOURCES.md` 署名与说明。

已在1280×800、1366×768、1920×1080下检查60个页面位置和45个阅读场景，未发现横向溢出或阅读框越界。另验证日夜模式、空邮箱联系入口、关闭返回焦点、视图的前进后退/刷新/非法hash回退、键盘切换、文章筛选、减少动态效果，以及三尺寸下24字昵称与400字介绍。测试资料与主题已恢复。

`dist/previews/` 新增十张1366×768真实页面截图；对比页全部加载正常，无模拟图。彩色与灰度对照、交互和几何记录位于不发布的 `qa/five/`。静态检查覆盖12页和298个本地引用，零错误。

Sites 沿用 `.openai/hosting.json` 的项目和原私有权限。草稿与 `qa/` 不在发布目录内。
