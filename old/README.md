# 历史方案归档

本目录保存正式 Vue 重构前的各版个人小站，供查看、对照和追溯。

- `personal-space/`：原生 HTML/CSS/JS 工程，包含模板、构建脚本、页面与素材、设计说明及已有验证记录。
- `*.tar.gz`：此前各轮发布打包文件。
- `*.png`：此前保存的预览图。

旧工程的 `dist/` 含可直接预览的页面、共用样式和素材，因此随归档保留。进入 `personal-space/` 运行 `node server.cjs`，可按终端提示预览历史页面；完整方案索引和原构建方式见 [旧工程说明](./personal-space/README.md)。

归档不参与正式前端构建。这里原来的独立 Git 元数据已移除，后续统一由项目根目录的 Git 仓库管理；忽略规则也统一放在根目录。
